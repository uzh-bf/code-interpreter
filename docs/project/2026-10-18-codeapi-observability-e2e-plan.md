For the deterministic integration lane, generate a fresh synthetic fixture and artifact name per test. This lane runs only in an operator-started, task-scoped local/container consumer connected through existing connectivity to STG. Ordinary CI/mock tests receive no live endpoint or signing key. An explicit real-service opt-in requires the expected profile, real endpoint and approved signing capability, and fails early if any is missing.

The deployed-browser lane runs outside CI against the bound application using an existing approved synthetic account.
